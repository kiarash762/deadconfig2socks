# Proxy IP & SOCKS5 Harvester 🚀

مجموعه ابزارهای خودکار پایتون برای استخراج، فیلتر و تبدیل کانفیگ‌های پراکسی به آی‌پی‌های فعال و در نهایت کشف پورت‌های باز جهت ساخت کانکشن‌های SOCKS5.

---

## 📌 معرفی پروژه

این مخزن شامل دو اسکریپت اصلی برای ساخت یک خط لوله (Pipeline) کامل پردازش کانفیگ‌های شبکه است:

1. **`config_to_IP.py`**:
   کانفیگ‌های پراکسی (از جمله پروتکل‌های مختلف) را از فایل `config.txt` خوانده، مقادیر Base64 و ساختارهای JSON را دیکود کرده و آدرس‌های IPv4 معتبر و یکتا را در `ip.txt` ذخیره می‌کند.
2. **`IP-to-socks.py`**:
   آی‌پی‌های به‌دست‌آمده از مرحله قبل را به‌صورت ناهمگام (Async) پینگ می‌کند تا هاست‌های زنده مشخص شوند؛ سپس با استفاده از **Nmap** پورت‌های باز آن‌ها را با سرعت بالا اسکن کرده و لینک‌های نهایی SOCKS5 را در `configs.txt` می‌سازد.

---

## 🛠 پروتکل‌های پشتیبانی‌شده در استخراج آی‌پی

- **VMess** (`vmess://`)
- **VLESS** (`vless://`)
- **Trojan** (`trojan://`)
- **Shadowsocks / SSR** (`ss://`, `ssr://`)
- **SOCKS / SOCKS5** (`socks://`, `socks5://`)
- **Hysteria / Hysteria 2** (`hysteria2://`, `hy2://`)
- **TUIC** (`tuic://`)

## ⚙️ پیش‌نیازها

1. **پایتون:** نسخه 3.8 یا بالاتر
2. **ابزار Nmap:** باید روی سیستم نصب شده و در متغیر محیطی PATH قرار داشته باشد.
   - **ویندوز:** دانلود و نصب از [nmap.org](https://nmap.org/download.html)
   - **لینوکس (اوبونتو/دبیان):**
     ```bash
     sudo apt update && sudo apt install nmap -y
     ```

## 🚀 راهنمای گام‌به‌گام اجرا

### مرحله اول: استخراج آی‌پی‌ها (`config_to_IP.py`)

1. کانفیگ‌های اولیه خود را خط به خط داخل فایلی به نام `config.txt` در کنار اسکریپت‌ها قرار دهید.
2. اسکریپت استخراج را اجرا کنید:
   ```bash
   python config_to_IP.py
   ```
3. این اسکریپت تمام آی‌پی‌های معتبر IPv4 را استخراج، موارد تکراری را حذف و خروجی را در فایلی به نام `ip.txt` ذخیره می‌کند.

---

### مرحله دوم: تست، اسکن و ساخت SOCKS5 (`IP-to-socks.py`)

1. مطمئن شوید فایل `ip.txt` در پوشه جاری موجود است.
2. اسکریپت دوم را اجرا کنید:
   ```bash
   python IP-to-socks.py
   ```
3. مراحل پردازش:
   - **Stage 1:** پینگ موازی تا سقف ۲۰۰ درخواست همزمان جهت یافتن آی‌پی‌های آنلاین.
   - **Stage 2:** اسکن موازی پورت‌های باز با Nmap (همزمان ۵ اسکن جهت بهینه‌سازی بار پردازشی شبکه و سیستم).
   - **Stage 3:** ساخت لینک‌های `socks5://IP:PORT` و ذخیره در فایل `configs.txt`.

## 📁 ساختار فایل‌های پروژه

```text
├── config_to_IP.py     # اسکریپت استخراج IPv4 از کانفیگ‌ها
├── IP-to-socks.py      # اسکریپت بررسی پینگ، اسکن پورت و تولید ساکس۵
├── config.txt          # فایل ورودی کانفیگ‌ها (ایجاد توسط کاربر)
├── ip.txt              # فایل میانی حاوی آی‌پی‌های تمیز و یکتا
├── configs.txt         # خروجی نهایی لینک‌های SOCKS5
└── README.md           # مستندات و راهنمای پروژه
```

## ⚡ تنظیمات پیشرفته (Performance Tuning)

در فایل `IP-to-socks.py` می‌توانید بر اساس منابع شبکه و سخت‌افزار مقادیر زیر را سفارشی کنید:

- `PING_SEMAPHORE = asyncio.Semaphore(200)`: تعداد پینگ‌های همزمان.
- `NMAP_SEMAPHORE = asyncio.Semaphore(5)`: تعداد اسکن‌های همزمان Nmap.
- پارامتر `--min-rate 2000` در دستور Nmap: نرخ ارسال بسته‌ها در ثانیه برای افزایش سرعت اسکن پورت‌ها.
